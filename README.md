# Информационная система управления проектами компании

Учебный проект по теме «Информационная система управления проектами компании» в рамках учебной практики МТУСИ.

Проект предназначен для учета проектов, задач и сотрудников, назначения исполнителей и контроля выполнения работ.

## Структура

- database/schema.sql — структура базы данных;
- docs/requirements.md — требования к системе;
- docs/architecture.md — описание архитектуры;
- src/ — исходные материалы прототипа.
