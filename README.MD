# Информационная система управления проектами компании

## Описание проекта

Веб-приложение для автоматизации управления проектами компании. Система позволяет управлять сотрудниками, создавать проекты, распределять задачи и контролировать ход их выполнения.

## Основные возможности

- Просмотр статистики на главной панели управления.
- Добавление, редактирование и удаление сотрудников.
- Создание, редактирование и удаление проектов.
- Назначение руководителей проектов.
- Создание и редактирование задач.
- Назначение нескольких исполнителей на одну задачу.
- Изменение приоритета и статуса задач.
- Хранение информации в базе данных SQLite.

## Используемые технологии

- Python 3.10
- Flask
- SQLite
- HTML5
- CSS3
- Jinja2

## Установка и запуск

1. Склонировать репозиторий.
2. Создать виртуальное окружение:

```bash
py -m venv .venv
```

3. Активировать его в Windows:

```powershell
.\.venv\Scripts\Activate.ps1
```

4. Установить зависимости:

```bash
py -m pip install -r requirements.txt
```

5. Создать базу данных:

```bash
py database.py
```

6. Запустить приложение:

```bash
py app.py
```

7. Открыть в браузере:

http://127.0.0.1:5000
