# Архитектура системы

Предполагается трехуровневая структура:

1. уровень представления — пользовательский интерфейс;
2. уровень бизнес-логики — обработка операций;
3. уровень данных — реляционная база данных.

Основные сущности: сотрудники, проекты, задачи и назначения сотрудников на задачи.

Связь сотрудников и задач является много-ко-многим и реализуется таблицей task_workers.
